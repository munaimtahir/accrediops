# Dedicated CAPA Board & Management Dashboards Sprint

Timestamp: 2026-05-16 21:42 UTC

## Objective
Create a dedicated CAPA management workspace for cross-project oversight without rebuilding CAPA.

In scope:
- Dedicated project-level CAPA dashboard and CAPA board views.
- My CAPA tasks view.
- CAPA detail drawer/page reuse or creation (management-friendly).
- Minimal backend additions only if required for dashboard queries.
- Navigation entrypoint into the CAPA workspace.

Out of scope:
- Advanced analytics, notifications/reminders.
- Rebuilding backend models or evidence workflow.
- Changes to production routing/DNS/Caddy/unrelated services.

## Deliverables (Target)
- Route: project-level CAPA workspace (dashboard + board + my tasks).
- Filters/search for management use.
- Actions gated by existing permissions/capabilities.
- Links back to indicator + evidence requirement.
- Baseline verification + updated test results.
