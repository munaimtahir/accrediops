# PHASE 2 — CURRENT EVIDENCE PACK AUDIT

This document audits the current state of the evidence pack and export functionality based on a review of the codebase.

| Area                           | Existing? | Complete? | Gap                                                                                                                                                            | Files involved                                                                                                                                                       |
| ------------------------------ | --------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Project print pack page**    | Yes       | Yes       | The page exists and renders data from the backend.                                                                                                             | `frontend/app/(workbench)/projects/[projectId]/print-pack/page.tsx`, `frontend/components/screens/project-print-pack-screen.tsx`                          |
| **Generate print pack button** | Yes       | Yes       | The button exists and correctly reflects the project's readiness state (enabled/disabled).                                                                   | `frontend/components/screens/project-print-pack-screen.tsx`                                                                                                          |
| **Export history**             | Yes       | Yes       | The `ExportJob` model and `ExportHistoryView` API exist to track generated exports.                                                                            | `backend/apps/exports/models.py`, `backend/apps/api/views/admin.py`                                                                                                    |
| **Evidence ordering**          | Yes       | Yes       | The `PrintPackItem` model allows for custom ordering of evidence, which the `build_print_bundle` service respects.                                             | `backend/apps/exports/models.py`, `backend/apps/exports/services.py`                                                                                                 |
| **Missing evidence listing**   | No        | No        | The readiness check flags if evidence is missing, but the final generated pack does not contain a dedicated list of missing items.                               | -                                                                                                                                                                    |
| **Approved evidence listing**  | Partial   | No        | The pack lists evidence and its status, but does not provide a separate, clean list of only the approved items.                                                | -                                                                                                                                                                    |
| **AI-generated draft listing** | No        | No        | The entire export process is unaware of `DocumentDraft` models. AI drafts are not included in any form.                                                        | -                                                                                                                                                                    |
| **Draft vs final evidence**    | No        | No        | Since AI drafts are not included, there is no distinction made.                                                                                                | -                                                                                                                                                                    |
| **Reviewer/approval status**   | Partial   | No        | The pack shows the `approval_status` of evidence but lacks details on who performed the review/approval and when.                                              | `backend/apps/exports/services.py`                                                                                                                                   |
| **Framework grouping**         | Yes       | Yes       | The `build_print_bundle` service correctly groups indicators by `area` and `standard` based on their `sort_order`.                                               | `backend/apps/exports/services.py`                                                                                                                                   |
| **Inspection readiness summary** | Yes     | Partial   | The backend `export_eligibility_report` service calculates readiness, but this summary is not included on the cover page or as part of the final exported data. | `backend/apps/exports/services.py`                                                                                                                                   |
| **Download/export format**     | Partial   | No        | The API returns JSON data, but the frontend only previews it. There is no user-facing download or print-friendly format.                                      | `frontend/components/screens/project-print-pack-screen.tsx`                                                                                                          |
| **Backend service/API**        | Yes       | Yes       | The `build_print_bundle` service and `ProjectPrintBundleExportView` API endpoint are implemented.                                                              | `backend/apps/exports/services.py`, `backend/apps/api/views/exports.py`                                                                                              |
| **Frontend UI**                | Yes       | Partial   | A preview screen exists but lacks download functionality and does not display many of the required data points (drafts, missing items, etc.).                    | `frontend/components/screens/project-print-pack-screen.tsx`                                                                                                          |
| **Tests**                      | Yes       | Partial   | Basic tests exist but do not cover ordering, grouping, or the identified gaps like AI drafts or readiness summary inclusion.                                   | `backend/apps/api/tests/test_print_pack.py`                                                                                                                          |
