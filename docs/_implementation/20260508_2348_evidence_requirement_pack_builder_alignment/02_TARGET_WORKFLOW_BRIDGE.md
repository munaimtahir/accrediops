# 02 — Target Workflow Bridge

## Target chain
`Framework Indicator -> Evidence Requirement -> Project Indicator -> Evidence Fulfillment -> Generated Draft/Uploaded Proof -> Review -> Gap/CAPA -> Approval -> Final Inspection Pack`

## Principles
- Framework defines reusable requirement templates.
- Project tracks fulfillment state against those templates.
- AI remains advisory; human approvals govern compliance state.
- Final export is dynamic by framework area/standard structure.

## Example 1 — Waste segregation
- Indicator: Waste segregation is practiced.
- Requirements:
  1. SOP for segregation workflow.
  2. Waste disposal register.
  3. Photo evidence of color-coded bins.
  4. Staff training attendance.
- Fulfillment:
  - SOP: AI draft allowed, then human-reviewed.
  - Register: template may be generated; site record required.
  - Photos: physical/site upload only.
  - Training: uploaded signed record.

## Example 2 — Emergency tray
- Indicator: Emergency medicines/tray maintained.
- Requirements:
  1. Emergency tray checklist.
  2. Stock verification register.
  3. Expiry check evidence.
- Fulfillment includes periodic updates, reviewer checks, and approval.

## Example 3 — Staff file/training
- Indicator: HR file and training compliance maintained.
- Requirements:
  1. Staff file completeness checklist.
  2. Mandatory training matrix.
  3. Signed orientation/training records.
