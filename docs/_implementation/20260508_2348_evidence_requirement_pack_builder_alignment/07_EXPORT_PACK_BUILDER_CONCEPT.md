# 07 — Export Pack Builder Concept

## Modes
1. Set-wise export (working usage).
2. Final standard-wise inspection export (submission usage).

## Dynamic structure requirement
- Build output by framework area/standard/indicator ordering.
- Avoid hardcoded PHC/MSDS-only structures.

## Required final pack outputs (minimum)
- Master evidence index.
- Document register.
- Missing evidence report.
- Pending gap/CAPA report.
- Final readiness summary.
- Standard-wise preview payload (ZIP generation optional if deferred).

## Inclusion rules
- Include approved generated docs and approved uploaded evidence.
- Exclude rejected items from approved set.
- Keep missing/partial/open CAPA in separate sections.
